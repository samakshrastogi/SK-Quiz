# Implementation Roadmap

## Stage 1: Foundation

- Monorepo architecture.
- Shared contracts.
- API hardening and data model.
- First web shell and feature surfaces.
- AI service boundary.

## Stage 2: Authentication

- Refresh token rotation.
- Google OAuth callback flow.
- Email verification.
- Forgot/reset password.
- Session dashboard.

## Stage 3: AI Discovery and Questions

- Persist prompt versions in database.
- Question batch generator.
- Duplicate detection using content hashes.
- AI fallback and moderation workflows.

## Stage 4: Quiz Engine

- Resume state.
- Auto-save.
- Keyboard navigation.
- Adaptive batch refill.
- Full report generation.

## Stage 5: Scale and Operations

- Observability.
- Audit logs.
- Admin moderation flows.
- Load testing.
- Deployment pipelines.
